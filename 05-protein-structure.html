蛋白質結構預測

AlphaFold 2、AlphaFold 3、ESMFold、RoseTTAFold——AI 解開了 50 年的 protein folding problem。本章帶你看懂這些模型的核心思想、輸出與限制。

AlphaFold 2, AlphaFold 3, ESMFold, RoseTTAFold — AI cracked a 50-year-old problem. Here's how to read the outputs and avoid the gotchas.

背景

一、Protein folding 問題的 50 年

1972 年 Anfinsen 提出「序列決定結構」的 dogma，但用物理模擬精確算出折疊所需的算力過於龐大 (Levinthal 悖論)。從 1994 年起每兩年一次的 CASP 比賽記錄了這個領域的進展：

  • CASP 1-12 (1994-2016)：物理 + 統計能量函數，平均 GDT-TS 30-50 分。
  • CASP 13 (2018)：DeepMind 首次參賽 (AlphaFold 1)，平均 ~58 分，首次大幅領先。
  • CASP 14 (2020)：AlphaFold 2 平均 ~92 分——進入「實驗等級」，本領域被認為已基本解決。
  • CASP 15 (2022)：RosettaFold-AllAtom、ESMFold 在無 MSA 場景接近 AlphaFold 2。
  • 2024：AlphaFold 3 公開論文 (Nature)；2025 發布權重供非商業使用。

Anfinsen's 1972 dogma — sequence determines structure — was clear, but the compute to fold a protein from physics is intractable (Levinthal paradox). The CASP competition (held biennially since 1994) tracks the field:

  • CASP 1–12 (1994–2016): physics + statistical potentials, average GDT-TS 30–50.
  • CASP 13 (2018): DeepMind's first AlphaFold scored ~58 — first major leap.
  • CASP 14 (2020): AlphaFold 2 averaged ~92 — experimental quality. Considered the problem largely solved.
  • CASP 15 (2022): RoseTTAFold-AllAtom, ESMFold approach AlphaFold 2 without MSAs.
  • 2024: AlphaFold 3 paper (Nature). 2025: weights released for non-commercial use.
架構

二、AlphaFold 2 vs 3：兩種思路

AlphaFold 2 (2020)AlphaFold 3 (2024)
輸入MSA + 模板結構MSA + 任意分子
主幹Evoformer + Structure ModulePairformer + Diffusion module
輸出僅蛋白質任意分子複合物
置信度pLDDT, PAEpLDDT, PAE, ipTM
精度蛋白單體 ~92 GDTprotein-ligand 較 docking 工具提升 50%
💡
關鍵直覺：AF2 用「幾何回歸」直接預測座標；AF3 用「擴散去噪」從原子雲逐步精修——後者天然支持任意分子，因為去噪不依賴特定原子類型。 Key intuition: AF2 directly regresses coordinates ("geometric regression"); AF3 starts from an atom cloud and iteratively denoises ("diffusion"). The latter naturally supports any molecule because denoising is atom-type agnostic.
解讀輸出

三、看懂 pLDDT 顏色等於看懂結果

pLDDT (predicted Local Distance Difference Test) 是模型對「每個原子位置」的自信度，範圍 0-100。AlphaFold 在所有結構上以「顏色」傳達：

pLDDT (predicted Local Distance Difference Test) is the model's per-atom confidence, on a 0–100 scale. AlphaFold encodes it visually:

pLDDT > 90 — 深藍

非常自信。Side-chain 與骨架皆可信，可用於 docking、突變設計。

Very high confidence. Side chains and backbone trustworthy — usable for docking and mutation design.

70-90 — 淺藍

自信。骨架可信；side-chain 需謹慎。

Confident. Backbone reliable; treat side chains with care.

50-70 — 黃

低信心。可能是柔性區段，或 MSA 訊息不足。

Low confidence. Possibly flexible region or thin MSA.

< 50 — 橘

極低信心，通常是內在無序區 (IDR)Intrinsically disordered region：天然就沒有固定結構或預測失敗。不要直接用做下游分析。

Very low confidence — usually an intrinsically disordered region (IDR)Naturally has no fixed structure or a prediction failure. Do not use for downstream analysis.

⚠️
常見誤用：把整個結構平均成一個「pLDDT 分數」就是浪費資訊。正確做法是逐殘基檢查；多體 (multimer) 還要看 PAE (predicted aligned error) 與 ipTM (interface pTM)。 Common misuse: averaging pLDDT to one number throws away the per-residue signal. Always inspect per-residue, and for multimers, also check PAE (predicted aligned error) and ipTM (interface pTM).
動手

四、用 ESMFold 5 行程式碼預測一個結構

ESMFold 不需要 MSA，速度比 AlphaFold 2 快約 60 倍，雖然精度略低 (~85 GDT)，是 prototype 與大規模篩選的首選。

ESMFold needs no MSA, runs ~60× faster than AlphaFold 2, and is ~85 GDT. The go-to for prototyping and large-scale screening.

# pip install fair-esm[esmfold]
import torch
from esm.pretrained import esmfold_v1

model = esmfold_v1().eval().cuda()
seq = "MKTFFVAGNWKMNGNRELLGEEFLKTLDS"
with torch.no_grad():
    out = model.infer_pdb(seq)             # PDB string
with open("out.pdb", "w") as f: f.write(out)
# Then visualize in PyMOL: pymol out.pdb
# AlphaFold 3 — public server is the easiest entry point
# https://alphafoldserver.com/  (free, non-commercial)
# For local: clone the released github repo, use NVIDIA H100/A100, follow weights request flow.

# For programmatic AlphaFold 2 use, ColabFold is the practical choice:
pip install colabfold
colabfold_batch input.fasta out_dir/ \
    --num-recycle 3 --templates --use-gpu-relax
陷阱

五、AlphaFold 不是萬能：什麼時候會失敗？

🌀 內在無序區 (IDR)

本來就沒有固定結構，模型只能猜。低 pLDDT 在這裡不是模型的錯——是反映生物學現實。

No fixed structure to predict. Low pLDDT here isn't a model failure — it reflects biology.

🧬 突變對結構的影響

AlphaFold 2 對單點突變的結構變化通常無感；想看突變影響應改用 AlphaMissense、ESM-1v 或進行 free-energy 模擬。

AlphaFold 2 is largely insensitive to single mutations. Use AlphaMissense, ESM-1v, or free-energy simulations instead.

🔗 多狀態構象

離子通道、轉運蛋白通常有 active/inactive 雙態，AlphaFold 只給一個答案；可借助多 seed 採樣 + AF-Cluster 啟動。

Channels and transporters have active/inactive states. AF gives one. Try multiple seeds + AF-Cluster.

🪨 條件相依結構

pH、磷酸化、配體結合會誘導構型變化——AlphaFold 沒看過這些條件。

pH, phosphorylation, ligand binding can induce changes — AF has no awareness of those conditions.

📝 概念小測 (3 題)

Q1. AlphaFold 3 相對於 AlphaFold 2 最關鍵的突破是？

(A) 蛋白質單體精度大幅提升
(B) 用擴散模組支援任意分子的複合物預測
(C) 不再需要序列輸入
(D) 改用 RNN 架構
✅ 正解 (B)

Q2. 你拿到一個 AlphaFold 結果，pLDDT 在 1-30 殘基為 35，30-200 為 88，最合理的解釋？

(A) 模型完全失敗，整個結構不可信
(B) N-端可能是訊號肽或 IDR；30-200 折疊核心可信
(C) 序列輸入錯了
(D) 這個蛋白質不存在
✅ 正解 (B)

Q3. 對「快速預測 10 萬條沒有同源序列的蛋白結構」最合適的工具？

(A) AlphaFold 2 全 MSA 流程
(B) ESMFold（無 MSA、~60× 快）
(C) 經典 Rosetta ab initio
(D) X-ray 結晶
✅ 正解 (B)
