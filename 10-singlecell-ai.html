單細胞基礎模型

scVI、scGPT、Geneformer、scFoundation：從一個樣本到千萬細胞圖譜，AI 在學「細胞語法」。zero-shot 註釋、擾動預測、跨樣本對齊都成為可能。

scVI, scGPT, Geneformer, scFoundation: AI learns the "grammar of cells" from tens of millions of single-cell profiles — enabling zero-shot annotation, perturbation prediction, and cross-sample alignment.

核心技巧

二、把細胞變成 token 序列

不像 NLP 句子有自然順序，scRNA-seq 細胞是「~20,000 維表達向量」。三種主流 tokenization：

  • Rank-based (Geneformer)：把每個細胞中表達量排名，取前 N 個基因 ID 作為 token 序列。簡單，但丟失絕對表達量。
  • Value-based binning (scGPT)：把連續表達量分箱成 token；既保留排序也保留量級。
  • Continuous embedding (scFoundation)：用 cross-attention 直接把連續值送入；不丟失資訊但實作較複雜。

Unlike NLP, single-cell data is a ~20,000-dim expression vector with no natural order. Three main tokenizations:

  • Rank-based (Geneformer): rank genes by expression in each cell, take the top-N IDs as a token sequence. Simple but loses absolute levels.
  • Value-based binning (scGPT): discretize continuous expression into bins. Keeps both order and magnitude.
  • Continuous embedding (scFoundation): cross-attention ingests continuous values directly. Lossless but more complex.
實戰

三、用 scVI 整合多個樣本

# pip install scvi-tools scanpy
import scanpy as sc, scvi

adata = sc.read_h5ad("merged.h5ad")            # with .obs["batch"] column
sc.pp.filter_genes(adata, min_cells=10)
sc.pp.highly_variable_genes(adata, n_top_genes=3000, batch_key="batch", subset=True)

scvi.model.SCVI.setup_anndata(adata, batch_key="batch")
mdl = scvi.model.SCVI(adata, n_latent=30)
mdl.train(max_epochs=200, early_stopping=True)

adata.obsm["X_scVI"]  = mdl.get_latent_representation()
sc.pp.neighbors(adata, use_rep="X_scVI"); sc.tl.umap(adata); sc.tl.leiden(adata)
sc.pl.umap(adata, color=["batch", "leiden"])         # batch effect should be dissolved
library(Seurat); library(reticulate)
sc <- import("scanpy"); scvi <- import("scvi")

obj <- readRDS("merged.rds")
obj <- FindVariableFeatures(obj, nfeatures = 3000)

ad <- sceasy::convertFormat(obj, from = "seurat", to = "anndata")
scvi$model$SCVI$setup_anndata(ad, batch_key = "batch")
m  <- scvi$model$SCVI(ad, n_latent = 30L)
m$train(max_epochs = 200L)

obj[["scVI"]] <- CreateDimReducObject(m$get_latent_representation(),
                                       key = "scVI_", assay = "RNA")
obj <- RunUMAP(obj, reduction = "scVI", dims = 1:30)
💡
scVI 仍是 2026 整合首選：輕量、效果穩定、生態完整 (totalVI 多模態, scANVI 半監督)。foundation model 在「沒有標籤的探索任務」上才開始勝出。 scVI is still the go-to for integration in 2026: lightweight, robust, with a full ecosystem (totalVI multi-modal, scANVI semi-supervised). Foundation models edge ahead mainly on label-free exploration.
進階

四、用 scGPT zero-shot 註釋細胞

# pip install scgpt
from scgpt.tasks import annotate
import scanpy as sc

adata = sc.read_h5ad("new_dataset.h5ad")        # your unlabeled query

result = annotate(
    adata,
    model_dir = "./scGPT_continual_pretrained",
    ref_h5ad  = "reference_atlas.h5ad",            # labeled reference
    cell_type_key = "cell_type",
    batch_key = "batch"
)
adata.obs["scgpt_pred"] = result.predictions
adata.obs["scgpt_conf"] = result.confidence
sc.pl.umap(adata, color=["scgpt_pred"])

關鍵心法：(1) reference atlas 越乾淨，預測越準；(2) 信心 < 0.5 的細胞應另設 "Unknown" 類別；(3) 對 reference 沒有的細胞型別，foundation model 會誤分到最近鄰類別——這是 zero-shot 的根本限制。

Key takeaways: (1) cleaner reference → better predictions; (2) flag confidence < 0.5 as "Unknown"; (3) for cell types not in the reference, the model will misassign to the nearest known type — a fundamental zero-shot limitation.

決策

五、要不要用 foundation model？

🌳 Quick guide

整合 + UMAP → scVI / Harmony 已足夠，foundation model 沒明顯加分
跨 atlas 對齊 → SCimilarity / UCE / scGPT
擾動預測 → scGPT / Geneformer (in silico KO)
罕見細胞型別 → Foundation model 可幫忙；但搭配 ML baseline 確認
算力極少 → 用 scVI；foundation model 推論成本高
