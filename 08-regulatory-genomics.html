CHAPTER 08 / 14 · INTERMEDIATE

調控基因體 AI

DeepSEA → Basenji → Enformer → Borzoi → AlphaGenome：從 DNA 序列直接預測表達量、染色質可及性、3D folding。長距離 attention 把調控「黑箱」打開了一個視窗。

DeepSEA → Basenji → Enformer → Borzoi → AlphaGenome: predicting expression, chromatin accessibility, and 3D folding from raw DNA. Long-range attention cracked open the regulatory black box.

背景

一、為什麼這個領域 5 年內換了 5 次代？

ModelYearContext預測目標
DeepBind, DeepSEA20151 kbTF binding, chromatin marks
Basenji / Basenji 22018-20131 kbCAGE, ATAC, ChIP-seq tracks
Enformer2021200 kb5,313 tracks (CAGE, ATAC, ChIP)
Borzoi / Flashzoi2024-25524 kbRNA-seq coverage (per-bp)
AlphaGenome20251 MbMulti-modal: expression + accessibility + 3D

每一代「視野更大、預測更細」。這之所以重要：90% 以上 GWAS hits 在非編碼區，要解讀它們的功能，模型必須能看到 enhancer 與 gene body 之間的距離（常常 100kb–500kb）。

Each generation sees further and predicts finer. This matters because >90% of GWAS hits are non-coding — interpreting them requires looking from the enhancer all the way to the gene body, often 100kb–500kb apart.

架構

二、Enformer 的架構直覺

Enformer 是 2021 年 DeepMind 發表的經典：

  1. 輸入 196,608 bp 的 one-hot DNA。
  2. 7 層 conv + max pool 把序列壓到 128 bp 解析度的 1,536-dim embedding（共 1,536 個位置）。
  3. 11 層 Transformer 在這 1,536 個 token 上做 long-range attention。
  4. 輸出 5,313 條軌跡 × 896 個 bin × 128 bp，覆蓋人類與小鼠的 CAGE / ATAC / ChIP-seq。

Borzoi 把第 4 步換成「逐 bp RNA-seq coverage」，因此能直接做 splice junction、3' UTR 變異效應預測。

Enformer (DeepMind, 2021) at a glance:

  1. Input 196,608 bp one-hot DNA.
  2. 7 conv + max-pool layers compress to 128 bp resolution × 1,536-dim embeddings (1,536 positions).
  3. 11 Transformer layers apply long-range attention across those 1,536 tokens.
  4. Output 5,313 tracks × 896 bins × 128 bp, covering human/mouse CAGE/ATAC/ChIP-seq.

Borzoi swaps step 4 with per-bp RNA-seq coverage, enabling direct prediction of splice junctions and 3'-UTR variant effects.

實戰

三、用 Enformer 做變異效應預測

核心想法：給定 SNP，將「ref 序列」和「alt 序列」分別丟給模型，比較預測軌跡的差異 (Δlog2FC)。

Key idea: feed both the ref and alt sequences to the model and compare the predicted track differences (Δlog2FC).

# pip install enformer-pytorch pyfaidx
import torch
from enformer_pytorch import Enformer, str_to_one_hot

mdl = Enformer.from_pretrained("EleutherAI/enformer-official-rough").eval().cuda()

ref = "AAGTC..."     # length 196,608, SNP at center
alt = ref[:98_303] + "T" + ref[98_304:]   # A→T

with torch.no_grad():
    p_ref = mdl(str_to_one_hot(ref).cuda())["human"]   # (896, 5313)
    p_alt = mdl(str_to_one_hot(alt).cuda())["human"]
delta = (p_alt - p_ref).abs().mean(0)               # per-track effect
top_tracks = delta.topk(10)               # most affected assays

限制

四、模型的盲點

🚧
2025 後一系列獨立研究發現：Enformer/Borzoi 在「個人基因組 (cross-individual)」表達預測上，比在「組織平均」表達上差得多——它們學到的是「sequence → average tissue expression」，不是「sequence → individual variation」。AlphaGenome 試圖修正，但仍未完全解決 personalized expression。 Independent 2025 studies show: Enformer/Borzoi work much worse on cross-individual expression than on tissue averages — they learn "sequence → tissue mean," not "sequence → individual variation." AlphaGenome partly addresses this but personalized expression remains open.

🪞 Cis vs Trans

模型只看區域內 DNA，無法捕捉 trans 效應 (TF 濃度差異、表觀遺傳狀態)。

Models only see local DNA — they can't capture trans effects (TF abundance, epigenetic state).

🔬 細胞型別解析

軌跡是 bulk 細胞型別。要做單細胞解析需 scBasset、ChromBPNet 等專門模型。

Tracks are bulk cell-types. For single-cell resolution, use scBasset, ChromBPNet.

決策

五、我該選哪個？

🌳 Quick guide

只要 expression → Borzoi (RNA-seq coverage 直出)
多種 assay → Enformer (5,313 tracks)
3D / 整合 → AlphaGenome (1 Mb context)
算力極少 → Flashzoi (Borzoi 蒸餾版，3× 快)
單細胞 ATAC → ChromBPNet, scBasset

📝 概念小測 (3 題)

Q1. 90% 以上 GWAS hits 在非編碼區，這對 AI 模型意味著？

(A) AI 完全沒用
(B) 模型必須能看見遠距離調控元件 (常 100kb-500kb)
(C) 應只看編碼區
(D) GWAS 沒有意義
✅ 正解 (B)

Q2. Enformer 為了同時得到大視野與細解析度，採用什麼架構策略？

(A) 純 CNN，128 層
(B) 先用 CNN 壓縮到 128bp 解析度，再用 Transformer attention 做長距離關聯
(C) 使用 RNN
(D) 只用 attention
✅ 正解 (B)

Q3. 你想預測一個非編碼 SNP 對 GWAS 候選基因的影響，最該怎麼做？

(A) BLAST 找同源
(B) 把含 ref 與 alt 等位的長序列分別輸入 Enformer/Borzoi，比較 Δexpression
(C) 跑全外顯子組
(D) 跳過，用 PolyPhen
✅ 正解 (B)
