CHAPTER 02 / 14 · BASIC

機器學習基礎

監督 vs 非監督、過擬合、AUROC 與 PR——所有 AI 模型背後的共通語言。本章用乳癌 (Wisconsin) 與 Iris 兩個經典資料集示範。

Supervised vs unsupervised, overfitting, AUROC and PR — the shared language under every AI model. Worked examples on the Wisconsin breast-cancer and Iris datasets.

核心概念

一、監督式 vs 非監督式 vs 自監督式

機器學習的本質就是從資料中學習一個函數，根據訓練時是否提供「正確答案 (label)」分為三大類：

Machine learning fundamentally means learning a function from data. Categorized by whether labels are provided during training:

🎯

監督式 (Supervised)

有 X 和 y。
例：依 SNP 預測糖尿病風險。
方法：邏輯回歸、Random Forest、XGBoost、神經網路。

Both X and y available.
Ex: predict T2D risk from SNPs.
Methods: logistic regression, RF, XGBoost, NN.

🔍

非監督式 (Unsupervised)

只有 X。
例：scRNA-seq 細胞分群。
方法：K-means、Louvain、UMAP、PCA、autoencoder。

X only.
Ex: scRNA-seq cell clustering.
Methods: K-means, Louvain, UMAP, PCA, autoencoders.

🪞

自監督式 (Self-supervised)

只有 X，自己產生「pretext label」。
例：ESM 遮蔽 15% 胺基酸再預測。
幾乎所有現代 foundation model 的訓練方式。

X only, with auto-generated pretext labels.
Ex: ESM masks 15% of residues and predicts them.
How nearly every modern foundation model is trained.

工作流程

二、Train / Validation / Test 切分

三組資料各自的角色：

  • Train (~70%)：模型用來學參數的資料。
  • Validation (~15%)：用來挑選超參數 (hyperparameter)，不能用來報告最終表現。
  • Test (~15%)：模型「真正沒看過」的資料，只做最後一次評估。

在生資中要特別小心 data leakage：例如同一個病人的多筆樣本同時出現在 train 與 test，或同一個基因家族跨組出現，都會讓表現「假好」。

Three roles:

  • Train (~70%) — fits the parameters.
  • Validation (~15%) — picks hyperparameters; never report performance from here.
  • Test (~15%) — held-out, evaluated only once.

In bioinformatics watch out for data leakage: the same patient appearing in train and test, or homologous genes split across folds, will artificially inflate metrics.

⚠️
分組切分原則：序列任務應做 sequence-identity split（避免訓練/測試序列相似度 > 30%）；病人資料用 group K-fold，同一病人的所有樣本只能在同一個 fold。 Splitting rules: for sequence tasks use sequence-identity splits (no train/test pairs > 30% identity); for patient data use group K-fold so all samples per patient stay in one fold.

四、分類任務的關鍵指標

指標計算什麼時候看？
Accuracy(TP+TN)/N類別平衡時。在罕見疾病等不平衡資料會誤導。
PrecisionTP/(TP+FP)不能容忍 false positive 時 (e.g. 臨床診斷)
Recall (Sensitivity)TP/(TP+FN)不能容忍 false negative 時 (e.g. 癌症篩檢)
AUROCROC 曲線下面積整體排序能力；不受 threshold 影響
AUPRCPR 曲線下面積類別嚴重不平衡時的首選（罕見變異、稀有細胞型別）
MCCMatthews 相關係數混淆矩陣的全包指標，類別不平衡時也合理
💡
經驗法則：類別比例 1:10 以上不平衡 → 別只看 accuracy 或 AUROC，務必加上 AUPRC 與 MCC。 Rule of thumb: imbalance ≥ 1:10 → don't rely on accuracy or AUROC alone; report AUPRC and MCC too.
動手實作

五、Wisconsin 乳癌資料集 — Logistic vs Random Forest

from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import roc_auc_score, average_precision_score

X, y = load_breast_cancer(return_X_y=True)
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.2, stratify=y, random_state=42)

for name, mdl in [("LogReg", LogisticRegression(max_iter=5000)),
                 ("RandomForest", RandomForestClassifier(n_estimators=300, random_state=42))]:
    mdl.fit(Xtr, ytr)
    p = mdl.predict_proba(Xte)[:, 1]
    print(name, "AUROC", round(roc_auc_score(yte, p), 3),
                "AUPRC", round(average_precision_score(yte, p), 3))
library(tidymodels); library(mlbench); data("BreastCancer")
df <- BreastCancer |> na.omit() |> mutate(across(2:10, as.numeric))

split <- initial_split(df, prop = 0.8, strata = Class)
tr <- training(split); te <- testing(split)

rec <- recipe(Class ~ ., data = tr) |> step_rm(Id) |> step_normalize(all_numeric_predictors())

logit <- logistic_reg() |> set_engine("glm")
rf    <- rand_forest(trees=300) |> set_mode("classification") |> set_engine("ranger")

workflow_set(list(rec=rec), list(logit=logit, rf=rf)) |>
  workflow_map("fit_resamples", resamples = vfold_cv(tr, v = 5, strata = Class),
               metrics = metric_set(roc_auc, pr_auc, mcc)) |>
  collect_metrics()

兩段程式碼會印出 AUROC 與 AUPRC，通常 RF 略勝；但 Logistic 模型可解釋性更強——在臨床場景常常更受歡迎。

Both snippets print AUROC and AUPRC. RF usually edges out, but logistic regression's interpretability often wins in clinical settings.

決策樹

六、選哪個 ML 模型？

🌳 Quick guide

N<1k → Logistic / Penalized regression（可解釋、不易過擬合）
1k-100k → XGBoost / LightGBM 是 tabular 王者；SHAP 解釋特徵重要性
>100k → 如果是序列/影像，跳到 DL（章 03）；若仍是 tabular，深層 GBM 仍很強
無標籤 → K-means / Louvain → UMAP 視覺化；之後做半監督

📝 概念小測 (3 題)

Q1. 你拿罕見疾病資料 (1:200 不平衡) 訓練分類器，AUROC=0.95，AUPRC=0.20。最合理的解讀是？

(A) 模型表現極佳
(B) 排序能力 OK，但實際應用中 precision 很低，誤報率仍高
(C) 資料一定有 bug
(D) AUPRC 沒有意義可以忽略
✅ 正解 (B)

Q2. 下列哪一種切分最容易導致「假好」?

(A) 對病人 ID 做 group K-fold
(B) 隨機 split — 同一病人在 train 與 test 各出現一次
(C) 序列相似度 30% 切分
(D) Stratified K-fold
✅ 正解 (B)

Q3. 自監督式 (self-supervised) 模型最大的優勢是？

(A) 不需要算力
(B) 可以利用海量無標籤序列預訓練，再以小量標籤資料 fine-tune
(C) 永遠比監督式準
(D) 不需要驗證集
✅ 正解 (B)
