變異判讀與剪接預測

DeepVariant 對抗 GATK、SpliceAI 把剪接變異 priority 化、AlphaMissense 給每個錯義 SNV 致病評分。臨床/研究上的標準工具與真實限制。

DeepVariant vs GATK; SpliceAI prioritizing splice variants; AlphaMissense scoring every missense SNV. Standard tools and their real-world limits.

變異判讀

一、DeepVariant 為什麼能贏 GATK？

傳統 GATK 採用機率圖模型 (HMM/Bayesian)基於假設族群基因型分佈與 read 錯誤率，計算後驗機率，需要專家手調超參數。DeepVariant 把問題轉成「影像識別」：

  1. 每個候選變異位點，產生一張 RGB 「pile-up image」——每行 read，欄是位置，channel 編碼 base、quality、strand 等。
  2. 用 Inception-v3 / EfficientNet 直接分類三類：homozygous ref、het、homozygous alt。

2025 benchmark 顯示，DeepVariant 在 SNV 上 precision 約 0.79，F1 約 0.88，較 GATK HaplotypeCaller 高 2-3 個百分點，特別是 long-read 與 PCR-free 樣本差距更大。

Traditional GATK uses probabilistic graph models (HMM/Bayesian)Based on assumed population genotype priors and read error rates, computing posterior probabilities with expert-tuned hyperparameters. DeepVariant reframes calling as image recognition:

  1. For each candidate site, build an RGB pile-up image — rows are reads, columns are positions, channels encode base, quality, strand, etc.
  2. An Inception-v3 / EfficientNet classifies into three classes: hom-ref, het, hom-alt.

2025 benchmarks: DeepVariant SNV precision ≈0.79, F1 ≈0.88 — ~2–3 points above GATK HaplotypeCaller, with larger gaps on long-read and PCR-free data.

⚠️
但別 100% 信任：DeepVariant 在訓練分佈外（如非人類物種、稀有結構變異 SV）會 silent failure。臨床流程通常雙工具 (GATK + DeepVariant) 取交集，再加 manual review。 Don't fully trust: DeepVariant has silent failures off-distribution (non-human species, rare SVs). Clinical pipelines typically run both GATK and DeepVariant and intersect, then manual review.
剪接預測

二、SpliceAI：把「剪接致病性」量化

SpliceAI (Illumina, Cell 2019) 用 32 層 dilated CNN 看 ±5,000 bp 上下文，對任何位點輸出兩個機率：(1) 該位點作為 acceptor、(2) 作為 donor。從一個變異前後機率差異 (Δscore)，可以給出 4 個值：

  • Acceptor gain / loss：acceptor 強度的增加 / 減少
  • Donor gain / loss：donor 強度的增加 / 減少

2025 年 medRxiv 一篇大型臨床研究 (n=7,220 罕見疾病患者) 發現：使用預先計算的 SpliceAI 分數會漏掉 18% 的剪接致病變異，主因是基因註解過時與 liftover 錯誤。重新用最新基因註解跑 SpliceAI 可額外獲得 11.7% 的診斷率提升。

SpliceAI (Illumina, Cell 2019) uses 32 dilated-CNN layers across ±5,000 bp context to output, for any position, two probabilities: (1) acts as acceptor, (2) acts as donor. Per variant, it gives 4 deltas:

  • Acceptor gain/loss
  • Donor gain/loss

A 2025 medRxiv study (n=7,220 rare-disease patients) found that precomputed SpliceAI scores miss 18% of splice-altering variants, mainly due to outdated gene annotations and liftover errors. Re-running SpliceAI with current annotations adds 11.7% diagnostic yield.

💡
最佳實踐：(1) 用最新 GENCODE 註解重跑，不要只查 dbNSFP precomputed；(2) 閾值通常 0.2-0.5；(3) 對 deep intronic 變異特別敏感——傳統 splice site predictor 漏掉的它常能抓到。 Best practices: (1) Re-run with current GENCODE annotations, don't rely on dbNSFP precomputed; (2) thresholds usually 0.2–0.5; (3) excels at deep-intronic variants traditional predictors miss.

動手

四、實戰：跑 SpliceAI + AlphaMissense

# pip install spliceai pyfaidx tensorflow
spliceai \
    -I input.vcf.gz \
    -O output.vcf.gz \
    -R hg38.fa \
    -A grch38                # latest gencode annotation file

# Output VCF gets a SpliceAI=<allele>|<gene>|<DS_AG>|<DS_AL>|<DS_DG>|<DS_DL>|<DP_AG>|... INFO field
# DS_AG/AL/DG/DL = delta scores 0..1; report variants with max(DS) >= 0.2
import pandas as pd
# Download from https://alphamissense.hegelab.org/ or AlphaFold DB precomputed table (~5 GB)
am = pd.read_csv("AlphaMissense_hg38.tsv.gz", sep="\t", comment="#",
                 names=["chrom","pos","ref","alt","genome","uniprot","transcript",
                        "protein_var","am_pathogenicity","am_class"])

# Lookup score for chr17:7676154 G>A (TP53 p.R273H)
hit = am[(am.chrom=="chr17") & (am.pos==7676154) & (am.alt=="A")]
print(hit[["protein_var","am_pathogenicity","am_class"]])
# am_class: likely_benign | ambiguous | likely_pathogenic

五、變異判讀流程怎麼配？

Calling

DeepVariant + GATK 取交集；長讀長加上 NanoVar/Sniffles。

Intersect DeepVariant + GATK; add NanoVar/Sniffles for long-reads.

Filtering

VAF、coverage、strand bias、gnomAD AF；移除常見 polymorphism。

VAF, coverage, strand bias, gnomAD AF; drop common polymorphisms.

Annotation

VEP / Ensembl; ClinVar; HGMD; SpliceAI on-the-fly (不要只查 precomputed)。

VEP/Ensembl; ClinVar; HGMD; SpliceAI on-the-fly (don't trust precomputed alone).

Pathogenicity

AlphaMissense + REVEL + ClinVar 共識；ACMG/AMP rule-based 加分。

AlphaMissense + REVEL + ClinVar consensus; ACMG/AMP rule-based scoring.

Manual review

IGV 看 read pile-up，臨床對照表型；AI ≠ 自動診斷。

Inspect read pile-ups in IGV; correlate with clinical phenotype. AI ≠ auto-diagnosis.

(B) 把 read pile-up 編成 image，可直接用成熟的 CNN 自動學習特徵

(A) SpliceAI 完全不可用
(B) 預先計算分數會漏掉約 18% 變異，主因是過時基因註解；應該重跑
