神經元

一、一個神經元到底在算什麼？

一個神經元做兩件事：(1) 把所有輸入線性加權求和再加 bias；(2) 通過非線性激活函數。整個深度學習就是這兩個動作的堆疊。

One neuron does two things: (1) take a weighted sum of inputs plus bias; (2) pass through a nonlinear activation. All of deep learning is a stack of these two operations.

y = σ( w1·x1 + w2·x2 + ... + wn·xn + b )

ReLU

max(0, x)。最常用，計算便宜，深層 CNN/MLP 默認選擇。

max(0, x). The default — cheap and works for deep MLPs/CNNs.

Sigmoid

1 / (1+e-x)。輸出 (0,1)，二元分類最後一層。深層中間用會 vanish。

1 / (1+e-x). Output (0,1) — final layer for binary classification. Vanishes when stacked deep.

GELU / SiLU

近年 Transformer 主流選擇 (GPT、ESM、AlphaFold 都用)。比 ReLU 平滑、收斂更快。

Default in modern Transformers (GPT, ESM, AlphaFold). Smoother than ReLU, converges faster.

二、Sigmoid 神經元計算器

調整權重 w 與 bias b，看單一神經元如何把輸入 x∈[-5,5] 映射到 (0,1)。注意 w 越大邊界越陡，b 改變決策邊界位置。

Adjust weight w and bias b to see how a single sigmoid neuron maps inputs to (0,1). Larger |w| sharpens the boundary; b shifts it.

三、CNN、RNN、Transformer：三種看資料的方式

Architecture關鍵直覺生資代表作缺點
CNN
(1D/2D conv)		局部 motif 檢測，平移不變性DeepBind, DeepSEA, Basenji, scBasset長距離互動需多層才能捕捉
RNN / LSTM序列順序、隱藏狀態傳遞早期 splicing 預測、CRF 標註逐步運算難並行；長距離訊號衰減
Transformer全連接 attention，可同時看序列任意兩位置ESM, AlphaFold 2/3, scGPT, Enformer, Evo 2O(L²) 記憶體；>100k token 才需要特殊技巧
💡
記憶口訣：CNN 看「局部」、RNN 看「順序」、Transformer 看「全局」。生物序列通常需要全局訊息（promoter 與 gene body 距離數十 kb），這就是為什麼 Transformer 在 2022 年後幾乎一統江山。 Mnemonic: CNN sees local, RNN sees sequential, Transformer sees global. Biology often needs global signal (promoters tens of kb from gene bodies) — which is why Transformers dominate post-2022.

四、用 PyTorch / R-torch 訓練一個 1D-CNN 分類 DNA motif

任務：給定 100bp 的 DNA 序列，分類是否含有特定 TF 結合 motif (簡化版)。

Task: given a 100bp DNA sequence, classify whether it contains a TF-binding motif (toy version).

import torch, torch.nn as nn

class DNACNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv = nn.Conv1d(4, 32, kernel_size=8, padding=3)   # 4 channels = A,C,G,T
        self.pool = nn.AdaptiveMaxPool1d(1)
        self.fc   = nn.Linear(32, 1)
    def forward(self, x):           # x: (B, 4, 100)
        h = torch.relu(self.conv(x))
        h = self.pool(h).squeeze(-1)
        return torch.sigmoid(self.fc(h)).squeeze(-1)

model = DNACNN(); opt = torch.optim.Adam(model.parameters(), lr=1e-3)
loss_fn = nn.BCELoss()

五、訓練 DL 的 7 個保命招數

先 overfit 一個 mini-batch

10 筆資料 train 100 epoch 應該幾乎 0 loss——做不到代表 model/loss/data 有 bug。

10 samples × 100 epochs should reach ~0 loss. If not, your model/loss/data has a bug.

LR 是最關鍵超參數

用 LR finder 從 1e-7 掃到 1e-1，找 loss 開始下降的甜蜜點。

Use an LR finder, sweeping 1e-7 → 1e-1; pick where loss starts dropping.

標準化輸入

數值特徵 z-score；DNA 用 one-hot；表達量用 log1p + scale。

z-score numeric; one-hot DNA; log1p + scale expression.

正則化

Dropout (0.1–0.5)、weight decay (1e-4)、early stopping；避免過擬合。

Dropout (0.1–0.5), weight decay (1e-4), early stopping — your shield against overfitting.

Reproducibility

固定 random seed (Python、NumPy、PyTorch、CUDA 都要)；記下版本與 commit。

Seed Python, NumPy, PyTorch, CUDA — all of them. Log versions and commits.

GPU 記憶體耗光？

先 mixed-precision (bf16/fp16)，再 gradient accumulation；最後才縮 batch。

Try mixed precision (bf16/fp16), then gradient accumulation; reduce batch only as last resort.

從 fine-tune 開始

生物 AI 別從零訓練——HuggingFace 上找 ESM、scGPT、DNABERT 都好。

Don't train bio models from scratch — fine-tune from HuggingFace (ESM, scGPT, DNABERT).

Q1. 為什麼現代 Transformer 在生物序列任務全面取代 RNN？

(A) Transformer 參數比較少
(B) Attention 可平行運算且能直接捕捉長距離依賴 (e.g. enhancer-promoter)
(C) RNN 已被禁用
(D) Transformer 不需要 GPU
✅ 正解 (B)

Q2. 訓練 loss 從第一個 epoch 就 nan，最可能的原因？

(A) 模型太深
(B) Learning rate 太大、輸入未正規化、log(0) 等數值問題
(C) Batch size 太小
(D) 一定是資料 bug
✅ 正解 (B)

Q3. 你的訓練集 5,000 條 DNA 序列要分類 enhancer。最佳策略？

(A) 從零訓練 100M 參數 Transformer
(B) Fine-tune 預訓練好的 DNABERT 或 Nucleotide Transformer
(C) 一定要用 ResNet50
(D) 只用統計方法
✅ 正解 (B)
