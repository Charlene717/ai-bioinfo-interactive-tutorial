CHAPTER 03 / 14 · BASIC

深度學習基礎

從一個神經元到 Transformer attention——用直覺、互動與最少數學穿越深度學習。學會這套「文法」後，AlphaFold 3 與 ESM-3 不再是黑魔法。

第一原理

一、一個神經元到底在算什麼？

深度學習聽起來嚇人，但一個神經元只做兩件事：線性加權求和 + 非線性激活。AlphaFold 3 只是這兩步驟堆疊了幾百萬次。

y = σ( w1·x1 + w2·x2 + ... + wn·xn + b )

為什麼要非線性激活？

沒有非線性激活，無論疊多少層都會攤平成一個線性函數。

像把多片透明色片疊在一起——必須中間夾一片「不均勻」的，才能產生複雜圖案。

ReLU

max(0, x)。最常用，計算便宜，深層 CNN/MLP 預設。
缺點：「dying ReLU」——神經元落到負值區後永遠不會更新（梯度=0）。

max(0, x). The default — cheap and works for deep MLPs/CNNs.
Drawback: "dying ReLU" — once a neuron lands in the negative region, gradient = 0 forever.

Sigmoid

1 / (1+e-x)。輸出 (0,1)，二元分類最後一層。
缺點：深層中間使用會梯度消失 (vanishing gradient)。

1 / (1+e-x). Output (0,1) — final layer for binary classification.
Drawback: vanishing gradient when stacked deep.

GELU / SiLU

近年 Transformer 主流選擇 (GPT、ESM、AlphaFold 都用)。比 ReLU 平滑、收斂更快。
GELU(x) = x · Φ(x)（Φ 為標準常態 CDF）

The de-facto choice in modern Transformers (GPT, ESM, AlphaFold). Smoother than ReLU, faster convergence.
GELU(x) = x · Φ(x) (Φ is the standard normal CDF).

互動模擬

二、Sigmoid 神經元計算器

調整 w 與 b，看單一神經元如何把 x 映射到 (0,1)。w 越大邊界越陡；b 改變邊界位置。

核心引擎

三、反向傳播：DL 的引擎

神經網路是一個「把輸入映射到 loss」的可微分函數。反向傳播用鏈鎖律一層一層計算梯度。

Forward pass：算預測與 loss

輸入 X 經過所有層得到 ŷ，與真 y 算 loss L(ŷ, y)。

X passes through all layers to produce ŷ, compute loss L(ŷ, y).

Backward pass：鏈鎖律算梯度

從最後一層往前，每層計算 ∂L/∂w 與 ∂L/∂b。PyTorch 的 loss.backward() 一行搞定。

From the last layer back, compute ∂L/∂w and ∂L/∂b for each layer. PyTorch's loss.backward() handles it.

Optimizer 更新參數

最簡單的 SGD: w ← w - η·∂L/∂w；現代多用 Adam 或 AdamW，會自適應每個參數的學習率。

Simplest SGD: w ← w - η·∂L/∂w; modern choice is usually Adam or AdamW, which adapts learning rate per-parameter.

重複幾百萬次

每次 mini-batch 都做一遍 1-3。AlphaFold 2 訓練了約 1 週 × 128 TPUv3。

Repeat 1-3 for each mini-batch. AlphaFold 2 trained for ~1 week on 128 TPUv3.

三大架構

四、CNN、RNN、Transformer

CNN — 局部偵測 + 平移不變

CNN：濾鏡滑動找 motif；DeepBind、DeepSEA、Basenji 用 CNN。

像用「找 TATA box 的印章」滑動檢查整條 DNA。

RNN / LSTM — 順序記憶

RNN：隱藏狀態順序傳遞；LSTM 加 gate 處理長距離。2022 後幾乎被 Transformer 取代。

像一邊讀小說一邊寫筆記——讀到第 100 頁時第 1 頁細節已模糊。

Transformer — 全連接 attention

Transformer：每個 token 看所有其他 token 並算 attention 權重。可平行，捕捉任意距離關係。

像圓桌會議——每個人發言時可同時看其他所有人，決定該重點關注誰。
💡
記憶口訣：CNN 看「局部」、RNN 看「順序」、Transformer 看「全局」。生物序列通常需要全局訊息（promoter 與 gene body 距離數十 kb），這就是為什麼 Transformer 在 2022 年後幾乎一統江山。 Mnemonic: CNN sees local, RNN sees sequential, Transformer sees global. Biology often needs global signal (promoters tens of kb from gene bodies) — which is why Transformers dominate post-2022.
Attention 拆解

五、Attention：用「查資料庫」的隱喻看穿它

Attention 看起來神秘，但本質就是「用 query 去查 key，加權拿回 value」。

Attention(Q, K, V) = softmax( Q·KT / √d ) · V
  • Q (Query)：「我要找什麼？」每個位置產生一個 query 向量
  • K (Key)：「我能匹配什麼？」每個位置產生一個 key 向量
  • V (Value)：「我有什麼內容？」每個位置產生一個 value 向量
  • Q·KT：算每個 query 對每個 key 的相似度（內積）
  • softmax：把相似度變成「機率權重」總和為 1
  • 權重 × V：依權重加權拿回 value

對蛋白質序列：當第 100 個殘基 (Q) 想知道它在 3D 空間的鄰居時，會去算它與其他每個殘基 (K) 的相似度，找到最可能空間接觸的位置，再把這些位置的 value 加權拼起來。這就是 AlphaFold 用 attention 從序列「猜出 3D 結構」的底層原理。

  • Q (Query): "What am I looking for?" — each position generates a query vector
  • K (Key): "What can I match?" — each position generates a key vector
  • V (Value): "What content do I carry?" — each position generates a value vector
  • Q·KT: compute similarity of every query to every key (dot product)
  • softmax: turn similarity into "probability weights" summing to 1
  • weights × V: weighted retrieval of values

For a protein sequence: when residue 100 (Q) wants to know its 3D neighbors, it scores its similarity to every other residue (K), identifies likely spatial contacts, then weighted-sums those positions' values. This is the foundation of how AlphaFold uses attention to 'infer 3D structure from sequence.'

實戰錦囊

六、訓練 DL 的 7 個保命招數

先 overfit 一個 mini-batch

10 筆資料 train 100 epoch 應該幾乎 0 loss——做不到代表 model/loss/data 有 bug。這比任何單元測試都有效。

10 samples × 100 epochs should reach ~0 loss. If not, your model/loss/data has a bug. More effective than any unit test.

LR 是最關鍵超參數

用 LR finder 從 1e-7 掃到 1e-1，找 loss 開始下降的甜蜜點。對 Transformer 通常 1e-4 ~ 5e-5 (fine-tune)、1e-3 ~ 5e-4 (from scratch)。

Use an LR finder, sweeping 1e-7 → 1e-1; pick where loss starts dropping. Transformer fine-tune is typically 1e-4 to 5e-5, from-scratch 1e-3 to 5e-4.

標準化輸入

數值特徵 z-score；DNA 用 one-hot；表達量用 log1p + scale；影像 0-255 → -1~1。輸入沒標準化是新手 #1 大坑。

z-score numeric; one-hot DNA; log1p + scale expression; images 0-255 → -1~1. The #1 beginner pitfall is unnormalized inputs.

正則化三件套

Dropout (0.1–0.5)、weight decay (1e-4)、early stopping。避免過擬合的基本配置。

Dropout (0.1–0.5), weight decay (1e-4), early stopping. Default anti-overfitting setup.

Reproducibility

固定 random seed (Python、NumPy、PyTorch、CUDA 都要)；記下版本與 commit；嚴格的話用 torch.use_deterministic_algorithms(True)。

Seed Python, NumPy, PyTorch, CUDA — all of them. Log versions and commits. For full determinism: torch.use_deterministic_algorithms(True).

GPU 記憶體耗光？

先 mixed-precision (bf16/fp16)，再 gradient accumulation，最後才縮 batch（縮 batch 影響 BatchNorm 與收斂）。Flash Attention 可省 5-10× 記憶體。

Try mixed precision (bf16/fp16), then gradient accumulation; reduce batch as last resort (it hurts BN/convergence). Flash Attention saves 5-10× memory.

從 fine-tune 開始

生物 AI 別從零訓練——HuggingFace 上找 ESM、scGPT、DNABERT 都好。從零訓練是奢侈，fine-tune 是工程。

Don't train bio models from scratch — fine-tune from HuggingFace (ESM, scGPT, DNABERT). Training from scratch is a luxury; fine-tuning is engineering.

動手實作

七、訓練一個 1D-CNN 分類 DNA motif

import torch, torch.nn as nn

class DNACNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv = nn.Conv1d(4, 32, kernel_size=8, padding=3)   # 4 channels = A,C,G,T
        self.pool = nn.AdaptiveMaxPool1d(1)
        self.drop = nn.Dropout(0.3)
        self.fc   = nn.Linear(32, 1)
    def forward(self, x):           # x: (B, 4, 100)
        h = torch.relu(self.conv(x))
        h = self.pool(h).squeeze(-1)
        h = self.drop(h)
        return torch.sigmoid(self.fc(h)).squeeze(-1)

model = DNACNN(); opt = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-4)
loss_fn = nn.BCELoss()

for epoch in range(10):
    pred = model(X); loss = loss_fn(pred, y)
    opt.zero_grad(); loss.backward()
    nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)    # 防止梯度爆炸
    opt.step()
    print(epoch, loss.item())

深入討論

八、爭議：scaling law 的天花板在哪裡？

Kaplan 等 (2020)、Hoffmann 等 (2022 Chinchilla) 提出的「scaling law」顯示：loss 隨參數量、資料量、算力呈冪次下降。直到 GPT-4 / Claude 3 / Gemini Ultra 這個層級，仍未看到平台期。生物模型 (ESM、Evo 2) 也在類似曲線上。

Kaplan et al. (2020) and Hoffmann et al. (2022 Chinchilla) showed scaling laws: loss falls as a power of params, data, and compute. Up through GPT-4 / Claude 3 / Gemini Ultra, no plateau in sight. Biological models (ESM, Evo 2) lie on similar curves.

Chinchilla 論文發現「最佳模型」其實是「同算力下多 token / 較小模型」。對生物：UniProt 約 240M 條蛋白，UniRef50 去冗餘後僅 60M——已接近 Evo 2 訓練量。如果不能擴增多樣化資料，模型再大也沒用。這就是為什麼合成生物學家正在實驗合成新蛋白序列來「擴增訓練集」。

Chinchilla showed the "compute-optimal" model uses more tokens / smaller params. For bio: UniProt has ~240M proteins, UniRef50 (deduplicated) only 60M — close to Evo 2's training set. Without more diverse data, bigger models don't help. Synthetic biologists are now experimenting with synthesizing novel sequences to "augment" the training set.

訓練 GPT-4 估計消耗 50 GWh 電力、釋放千噸 CO2。Strubell 等 (2019) 早就指出「大模型 = 大碳排」。即使技術上能繼續 scaling，全球能源限制可能讓「無限 scaling」不切實際。注重「sparse models」與「mixture-of-experts」可能比「dense scaling」更有未來。

Training GPT-4 reportedly consumed ~50 GWh, emitting thousands of tons of CO2. Strubell et al. (2019) flagged "big model = big carbon" early. Even if scaling is technically possible, global energy limits may make "infinite scaling" impractical. Sparse models and mixture-of-experts may have more future than dense scaling.
