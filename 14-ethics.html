CHAPTER 14 / 14 · BASIC

倫理、可重現性與最佳實踐

資料偏差、模型卡、FAIR、HIPAA/GDPR、Hallucination 控制、Benchmark 真相——技術強之外，AI 在生醫的「責任倫理」是必修課。

Data bias, model cards, FAIR, HIPAA/GDPR, hallucination control, benchmark realism — beyond raw capability, responsible AI in biomedicine is required reading.

資料偏差

一、AI 不會比訓練資料更公平

幾乎所有公開的人類基因組資料偏向歐裔（gnomAD ~75% 歐裔），這對下游 AI 預測有真實後果：

  • SpliceAI、AlphaMissense 在非歐裔變異上 false negative 率明顯較高。
  • 多基因風險分數 (PRS) 移植到不同族群時準確率可掉一半。
  • 單細胞 atlas 中亞洲、非洲樣本數仍 <15%，影響 scGPT/Geneformer 的 zero-shot 泛化。

緩解：報告 disaggregated metrics、多樣本族群 fine-tune、在 model card 明確標示適用人群。

Nearly all public human-genome data are European-skewed (gnomAD ~75% European). This has real downstream effects:

  • SpliceAI and AlphaMissense have higher false-negative rates on non-European variants.
  • Polygenic risk scores can lose half their accuracy when transferred across populations.
  • Asian/African samples are <15% of single-cell atlases, hurting scGPT/Geneformer zero-shot generalization.

Mitigations: report disaggregated metrics, fine-tune on diverse populations, clearly mark intended population in the model card.

Mitchell et al. 2019's Model Card is the de facto standard. For biomedical AI include at minimum:

📝 Intended use

「研究探索」 vs 「臨床決策」 vs 「教學」——明確切分，避免誤用。

"Research exploration" vs "clinical decision support" vs "education" — distinguish explicitly.

📊 Performance breakdown

族群、性別、年齡、組織別都要拆。單一全域 AUROC 不能算交差。

Break down by population, sex, age, tissue. A single global AUROC is not enough.

⚠️ Out-of-scope

明確列出「不該用」的場景：例如 AlphaFold 不適合 IDR 預測、scGPT 不適合 zero-shot 罕見細胞型別。

Explicitly list "do not use for" scenarios — AlphaFold isn't for IDRs, scGPT isn't for unseen rare cell types.

🔄 Versioning

權重 hash、訓練資料快照、reproduce 指令都需登記，讓未來研究者能 backtrack。

Weight hash, training-data snapshot, and repro commands logged so future readers can backtrack.

法規

三、FAIR + HIPAA/GDPR

FAIR

Findable、Accessible、Interoperable、Reusable。每個 dataset 要有 DOI、metadata、開放格式 (Parquet, AnnData, BAM)。

Findable, Accessible, Interoperable, Reusable. Every dataset gets a DOI, metadata, open format (Parquet, AnnData, BAM).

HIPAA / GDPR

美國 HIPAA、歐盟 GDPR、台灣個資法都嚴格規範 PHI。單純基因序列也算個資——de-identification 必須包含基因組去識別 (kinship masking)。

HIPAA (US), GDPR (EU), local laws all strictly regulate PHI. Genome sequence itself is identifying — proper de-identification includes kinship masking.

⚠️
2024 HHS 新規：美國 NIH 資金資助的研究若涉及生物樣本資料分享，必須走 dbGaP/AnVIL 等 controlled-access；不能直接放上 GitHub。 HHS 2024 update: NIH-funded studies sharing biosample data must use controlled-access platforms like dbGaP/AnVIL — public GitHub is not acceptable.
可重現性

四、讓你的流程可重現

環境鎖定

使用 conda env export + pip freeze，或 Docker / Singularity。生物資訊推薦 BioContainers。

Use conda env export + pip freeze, or Docker/Singularity. BioContainers is the bio standard.

工作流框架

Snakemake / Nextflow / WDL。nf-core 提供超過 100 個現成 pipeline，含 RNA-seq、scRNA、變異 calling。

Snakemake / Nextflow / WDL. nf-core ships 100+ ready pipelines for RNA-seq, scRNA, variant calling.

實驗追蹤

Weights & Biases、MLflow、Aim：超參數、資料 hash、metric 全部自動 log。

Weights & Biases, MLflow, Aim — auto-log hyperparams, data hash, metrics.

種子與決定性

Python、NumPy、PyTorch、CUDA 都要設 seed；某些 op 要用 torch.use_deterministic_algorithms(True)。

Seed Python, NumPy, PyTorch, CUDA. For full determinism use torch.use_deterministic_algorithms(True).

資料版本化

DVC、LakeFS、Git LFS：把資料指紋連同 code commit 一起追蹤。

DVC, LakeFS, Git LFS — track data fingerprints alongside code commits.

Benchmark 真相

五、別被 SOTA 數字騙了

🪞 資料洩漏

新模型的訓練 corpus 可能已包含 benchmark test set。請以時序切分 (e.g. PDB 2023 之後結構) 重評。

Modern training corpora often include benchmark test sets. Re-evaluate with temporal splits (e.g., PDB structures after 2023).

📊 Cherry-picked metric

論文常只報好看的指標。要求看 confusion matrix、PR 曲線、不同 subgroup。

Papers report flattering metrics. Demand confusion matrices, PR curves, and subgroup breakdowns.

📉 不同 baseline

「比 baseline 好 5%」常常是因為 baseline 沒調好。要求看「強 baseline」(調整過的 XGBoost / scVI / AutoDock Vina)。

"5% over baseline" often hides an under-tuned baseline. Demand a strong baseline (tuned XGBoost / scVI / AutoDock Vina).

📦 OOD 測試

同分佈 0.95 vs OOD 0.55，誰才是真實表現？OOD 結果決定模型在你資料上的命運。

0.95 in-distribution vs 0.55 OOD — which is "real"? The OOD number predicts what you'll see on your data.

總結

六、7 條黃金原則

1️⃣

先試簡單方法：經典 ML 是 baseline，不是落後。

Try the simple method first. Classical ML is your baseline, not a step backward.

2️⃣

切分要乾淨：sequence-identity / patient / temporal splits。

Split data cleanly: sequence-identity / patient / temporal.

3️⃣

看不確定性：pLDDT、置信度、bootstrap 區間。

Always report uncertainty: pLDDT, confidence, bootstrap intervals.

4️⃣

對族群與條件分別評估，不要只看全域 AUROC。

Evaluate per subgroup, not just global AUROC.

5️⃣

Reproducible is non-negotiable：環境、種子、資料版本一起記錄。

Reproducibility is non-negotiable. Track env, seed, and data version together.

6️⃣

Human-in-the-loop：高風險決策永遠不全自動。

Human-in-the-loop: high-risk decisions are never fully automated.

7️⃣

持續更新心智模型：AI 工具半年一個世代，留時間追文獻。

Keep updating your mental model. AI tools change every 6 months — schedule reading time.

📝 概念小測 (3 題)

Q1. 一篇論文宣稱新模型 AUROC=0.96，但只報全局指標。最該追問的是？

(A) 模型多大
(B) 各族群、各組織、OOD、時序切分的拆分結果
(C) 第一作者 ORCID
(D) 訓練了幾天
✅ 正解 (B)

Q2. PRS 在不同族群表現會掉一半的最常見原因是？

(A) 模型程式有 bug
(B) 訓練資料以歐裔為主，效應大小與 LD 結構不同
(C) PRS 過時
(D) 統計方法錯誤
✅ 正解 (B)

Q3. 你想分享 NIH 資助的人類 WGS 與 AI 訓練腳本。最合規的做法？

(A) 全部丟 GitHub public repo
(B) 程式碼放 GitHub；WGS 透過 dbGaP/AnVIL 等 controlled-access
(C) 只放 abstract
(D) 不分享
✅ 正解 (B)
