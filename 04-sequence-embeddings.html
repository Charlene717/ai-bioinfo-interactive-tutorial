生物序列嵌入

把 DNA、RNA、蛋白質序列「向量化」是所有下游 AI 任務的起點。從 k-mer 到 ESM、DNABERT、Nucleotide Transformer 與 Evo 2。

Vectorizing DNA, RNA, and protein sequences is the gateway to every downstream AI task. From k-mers to ESM, DNABERT, Nucleotide Transformer, and Evo 2.

核心概念

一、為什麼要「嵌入 (Embedding)」？

機器學習模型只懂「數字向量」，因此需要把字串序列轉成 向量通常是 128–2560 維的實數向量，每一維沒有單一語意，但向量之間的距離具有生物學意義。一個好的 embedding 會讓「功能相似」的序列在向量空間距離也相近。

嵌入的演進大致經歷三個世代：

ML models only understand numerical vectors, so we must convert sequence strings into vectorsUsually 128–2560-dimensional real-valued vectors. Individual dimensions have no single meaning, but distances between vectors carry biological meaning.. A good embedding places functionally similar sequences close together.

Three generations of embeddings:

🧮

第一代：k-mer / one-hot

把序列切成 k 個鹼基的子串計數，或直接 one-hot。簡單、可解釋；但忽略上下文。

Count substrings of length k, or one-hot. Simple, interpretable, but ignores context.

📈

第二代：word2vec / fastText

dna2vec、ProtVec：把 k-mer 當作 word 學習語境共現。維度低、計算快，曾是 2016-2019 主流。

dna2vec, ProtVec: treat k-mers as words and learn context co-occurrence. Dominant in 2016–2019.

🧠

第三代：Transformer 基礎模型

ESM-2/3、DNABERT-2、Nucleotide Transformer、Evo 2、scGPT。當前主流，最強。

ESM-2/3, DNABERT-2, Nucleotide Transformer, Evo 2, scGPT. The current state of the art.

三、Embedding 究竟長怎樣？

以 ESM-2 為例：輸入一條長度 L 的蛋白質序列，模型輸出一個 (L, D) 的張量，D 通常是 320–5120 維。常見用法：

  • 每個位置的 embedding：用於殘基級任務（如二級結構預測、結合位點偵測）。
  • 整條序列的 embedding：對 L 維度做 mean pooling，得到 (D,) 向量；用於蛋白質分類、相似度檢索。
  • contact map：從多頭 attention 的 head pattern 抽出，可推斷殘基-殘基接觸。

Take ESM-2 as an example: input a protein of length L, output a tensor of shape (L, D), with D typically 320–5120. Common patterns:

  • Per-residue: for residue-level tasks (secondary structure, binding sites).
  • Sequence-level: mean-pool along L → (D,) vector; protein classification or similarity search.
  • Contact map: extracted from attention heads — predicts residue-residue contacts.
protein_seq → ESM → embedding ∈ ℝL × D
動手

四、用 ESM-2 做蛋白質相似度檢索

import torch, numpy as np
from transformers import AutoTokenizer, AutoModel

tok = AutoTokenizer.from_pretrained("facebook/esm2_t12_35M_UR50D")
mdl = AutoModel.from_pretrained("facebook/esm2_t12_35M_UR50D").eval()

def embed(seq):
    enc = tok(seq, return_tensors="pt")
    with torch.no_grad():
        h = mdl(**enc).last_hidden_state[0, 1:-1]   # strip CLS/EOS
    return h.mean(0).numpy()                                # (480,)

queries = {"insulin": "MALWMRLLPLLALLALWGPDP...",
           "hemoglobin": "MVLSPADKTNVKAAWGKVGAH...",
           "GFP": "MVSKGEELFTGVVPILVELDGDVNGHKFSV..."}
embs = {n: embed(s) for n, s in queries.items()}

# cosine similarity matrix
import itertools
for a, b in itertools.combinations(embs, 2):
    cos = np.dot(embs[a], embs[b]) / (np.linalg.norm(embs[a]) * np.linalg.norm(embs[b]))
    print(f"{a} ↔ {b}: {cos:.3f}")
library(reticulate)
transformers <- import("transformers"); torch <- import("torch"); np <- import("numpy")

tok <- transformers$AutoTokenizer$from_pretrained("facebook/esm2_t12_35M_UR50D")
mdl <- transformers$AutoModel$from_pretrained("facebook/esm2_t12_35M_UR50D")$eval()

embed <- function(seq){
  enc <- tok(seq, return_tensors = "pt")
  res <- torch$no_grad(); on.exit(res$__exit__())
  h <- do.call(mdl, enc)$last_hidden_state[1, 2:(dim(enc$input_ids)[2] - 1), ]
  h$mean(0L)$numpy()
}
emb_a <- embed("MALWMRLLPLLALLALWGPDP...")
emb_b <- embed("MVLSPADKTNVKAAWGKVGAH...")
sum(emb_a * emb_b) / (sqrt(sum(emb_a^2)) * sqrt(sum(emb_b^2)))

cosine 相似度 0.7 以上通常代表功能相關。將整個 UniProt 編碼後存入 FAISSFacebook 的高速向量檢索庫，億級向量秒級查詢，就能做語意級的「BLAST 替代品」。

Cosine ≥ 0.7 usually means functional similarity. Index the whole UniProt with FAISSFacebook's high-speed vector search library — billion-vector queries in seconds and you have a semantic alternative to BLAST.

決策樹

五、該選哪個 embedding 模型？

🌳 Quick guide

蛋白質 → ESM-2 (35M-650M 平衡點) 或 ESM-3 (有結構任務時)
DNA < 1kb → DNABERT-2 / Nucleotide Transformer 500M
DNA 100kb-1Mb → HyenaDNA / Evo 2 7B
跨域 → Evo 2 (40B 模型可生成基因組片段)
算力吃緊 → 先 k-mer + Logistic 跑 baseline，再決定要不要上 DL
