## 使用方式 / How to use

1. 直接打開 `index.html`（雙擊或拖到瀏覽器）。
2. 右上角 EN/中文 按鈕切換語言。
3. 每章內含程式碼分頁（Python + R）、互動模擬、決策樹與隨堂小測。
4. 偏好離線環境：所有頁面都使用相對路徑與 CDN，可下載整個資料夾離線使用。

## 結構

- `index.html` — 14 章主題地圖（hub）
- `01-overview.html` … `14-ethics.html` — 各章
- `references.html` — 全部參考文獻與資料集
- `styles.css` — 共用樣式（紫色主題 + 互動元件）
- `i18n.js` — 雙語切換、進度條、Tab、Quiz 控制
