CHAPTER 01 / 14 · BASIC

AI × 生物資訊 概論

從序列、結構到細胞圖譜——AI 正在如何改寫整個生物資訊版圖？這一章是後續 13 個主題的地圖與心智模型。

From sequences and structures to cell atlases — how AI is rewriting bioinformatics. A roadmap and mental model for the 13 chapters that follow.

開場

為什麼現在是 AI × 生資的黃金交叉點？

三件事在 2020-2026 之間同時發生：(1) 資料指數級成長—UK Biobank 五十萬人全基因組、Human Cell Atlas 累計超過 5 千萬細胞、AlphaFold DB 提供 2 億條結構；(2) Transformer 跨領域成功—語言模型的「attention注意力機制：讓模型能同時關注序列上任意位置的關係，是現代生物 AI 的共同語言」在 DNA、蛋白質、單細胞 RNA-seq 上同樣有效；(3) 算力與開源權重—H100/B200、AlphaFold3 / ESM3 / Evo2 / scGPT 等大模型公開權重，讓中小實驗室也能在 fine-tune 階段參與創新。

這三股力量讓「能不能用 AI 做？」這個問題，從少數巨頭的特權，變成每個生資人需要面對的日常選擇。

Three things converged between 2020–2026: (1) data exploded — UK Biobank's 500K WGS, Human Cell Atlas's 50M+ cells, AlphaFold DB's 200M structures; (2) Transformers generalized — the same attentionAttention lets the model relate any two positions in a sequence — the lingua franca of modern bio-AI mechanism that powers language models works on DNA, protein, and scRNA-seq; (3) compute and open weights — H100/B200 GPUs, plus AlphaFold 3, ESM3, Evo 2, scGPT with public weights, lets small labs fine-tune frontier models.

Together, the question "can we use AI here?" has shifted from a Big-Tech privilege to a daily decision for every bioinformatician.

心智模型

生物資訊中 AI 的四層應用

不論你研究什麼物種或疾病，AI 在生資的應用大致可以歸入四個層級。每章都會回扣這個架構：

Regardless of organism or disease, AI in bioinformatics generally falls into four layers — every chapter ties back to this structure:

🧬

L1：序列 → 表徵

把 DNA / RNA / 蛋白質序列壓縮成資訊豐富的 embedding。代表：DNABERT、ESM、Nucleotide Transformer、Evo 2。下游任務 (function prediction、variant effect) 都建立在這層之上。

Compress DNA/RNA/protein sequences into rich embeddings. Examples: DNABERT, ESM, Nucleotide Transformer, Evo 2. Downstream tasks (function, variant effect) build on this layer.

🏗️

L2：序列 → 結構/功能

從序列直接推斷立體結構或功能：AlphaFold 3 (結構)、Enformer/Borzoi (表達量)、SpliceAI (剪接)、DeepVariant (變異品質)。

Predict 3D structure or function directly from sequence: AlphaFold 3 (structure), Enformer/Borzoi (expression), SpliceAI (splicing), DeepVariant (variant quality).

🧫

L3：細胞/組織 系統建模

整合大規模單細胞或空間轉錄組資料，學習通用的「細胞語法」：scVI、scGPT、Geneformer、scFoundation。可以做擾動預測、跨樣本對齊。

Integrate large-scale single-cell or spatial data to learn a universal "cellular grammar": scVI, scGPT, Geneformer, scFoundation. Enables perturbation prediction and cross-sample alignment.

📚

L4：知識合成 / Agent

用 LLM 整合文獻、資料庫、工具呼叫，產生分析腳本或診斷建議：BioGPT、Med-PaLM 2、CRISPR-Agent、AutoML pipelines。

Use LLMs to integrate literature, databases, and tool calls to draft scripts or clinical suggestions: BioGPT, Med-PaLM 2, CRISPR-Agent, AutoML pipelines.

🌳 決策路徑

Q1. 任務有標籤資料嗎？(>1000 筆)
→ 有：監督式 ML/DL（章 02、03）。少於 1000 筆優先嘗試傳統統計與經典 ML。
Q2. 輸入是序列嗎？
→ 是：看是 DNA / 蛋白 / RNA，分別查章 04、05、08、09。優先 fine-tune 現成 foundation model 而非從零訓練。
Q3. 是否需要可解釋與臨床合規？
→ 是：選擇有 attribution/saliency 工具的模型，並準備 model card（章 14）。
Q4. 任務是「總結 + 工具呼叫」型？
→ 是：考慮 RAG/Agent（章 12、13），但要做 hallucination 控制。

一段程式碼，五行解決一個生資任務

下面用 ESM-2 把蛋白質序列轉成嵌入向量（你會在第 4–5 章重新遇到它）。試著感受兩種語言寫法的等價性：

Below: ESM-2 turning a protein sequence into an embedding (you'll meet it again in Ch. 4–5). Notice how the two languages mirror each other:

# pip install fair-esm torch
import torch, esm
model, alphabet = esm.pretrained.esm2_t6_8M_UR50D()
batch = alphabet.get_batch_converter()([("GFP", "MSKGEELFTGV...")])
with torch.no_grad():
    out = model(batch[2], repr_layers=[6])
emb = out["representations"][6].mean(1)   # (1, 320)
# install.packages("reticulate"); reticulate::py_install("fair-esm")
library(reticulate); esm <- import("esm"); torch <- import("torch")
m  <- esm$pretrained$esm2_t6_8M_UR50D()
batch <- m[[2]]$get_batch_converter()(list(list("GFP", "MSKGEELFTGV...")))
out <- torch$no_grad()$__enter__(); res <- m[[1]](batch[[3]], repr_layers=c(6L))
emb <- res$representations[["6"]]$mean(1L)        # tensor shape (1, 320)
⚠️
R 使用者注意：蛋白質深度學習生態幾乎全在 Python，最佳做法是 reticulate 包裝呼叫，或使用 R-side 套件 torch 和 biostrings 處理序列前處理 + 向量分析。 R users: the protein deep-learning ecosystem is Python-first. Best practice is to call it via reticulate, while using R-native packages (torch, Biostrings) for preprocessing and downstream analysis.

📝 概念小測 (3 題)

Q1. 下列哪一項不是 2020-2026 推動 AI×生資的主要驅動力？

(A) UK Biobank 等大規模資料釋出
(B) Transformer 架構跨領域有效
(C) Sanger 定序技術突然變便宜 1000 倍
(D) AlphaFold3、ESM3 等大模型開放權重
✅ 正確答案 (C)。Sanger 並沒有突然降價；驅動力是 NGS 已經夠便宜 + 模型開源 + 算力充足。

Q2. 「序列 → 表徵」(L1) 與「序列 → 結構/功能」(L2) 的核心差別是？

(A) L1 輸出向量，是下游任務的輸入；L2 直接輸出生物學上有意義的結構或量化指標
(B) L1 必須使用 Transformer，L2 必須使用 CNN
(C) L1 是監督式，L2 是非監督式
(D) L1 只能處理 DNA，L2 只能處理蛋白質
✅ 正確答案 (A)。L1 是「特徵抽取」階段，L2 是「應用」階段；架構選擇與監督式與否是另一個維度。

Q3. 你接到一個任務：從 800 條腫瘤外顯子組篩選致病變異。你應該先嘗試？

(A) 從零訓練一個 Transformer 預測致病性
(B) 先用既有工具 (e.g. AlphaMissense、SpliceAI) + 經典 ML，800 筆遠不夠從零訓練 DL
(C) 跳過 AI，只用 VEP 注解
(D) 用一個大型 LLM 直接讀 VCF 給診斷
✅ 正確答案 (B)。資料量不大時，最佳實踐是把已訓練好的大模型作為特徵抽取器，再加上輕量分類器；章 9 會深入談這套流程。
