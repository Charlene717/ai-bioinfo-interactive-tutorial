蛋白質從頭設計

RFdiffusion 生成 backbone、ProteinMPNN 設計序列、AlphaFold 驗證——從零造一個自然界沒有的蛋白質，已經是端到端工業流程。

RFdiffusion generates backbones, ProteinMPNN writes sequences, AlphaFold validates — building a protein that doesn't exist in nature is now an end-to-end industrial pipeline.

總覽

一、三步驟：generate → design → validate

生成 backbone：RFdiffusion

把 RoseTTAFold 改裝成 diffusion model：從原子雜訊中逐步「去噪」出一個合理 3D 骨架。可指定限制——對稱性、結合 motif、活性中心 scaffold。

RoseTTAFold turned into a diffusion model: denoise atom noise into a plausible 3D backbone. Conditional inputs include symmetry, binding motifs, and active-site scaffolds.

設計序列：ProteinMPNN

給定 backbone 座標，使用 message-passing 神經網路為每個位置選胺基酸。實驗成功率 (~52%) 顯著高於物理 Rosetta (~10%)。

Given a backbone, a message-passing network picks an amino acid for each position. Experimental success ~52%, far above physics-based Rosetta (~10%).

驗證：AlphaFold + 實驗

用 AlphaFold 2/3 重新折疊「設計的序列」，看是否回到原本的 backbone（in silico 自洽）。pLDDT > 80 且 RMSD < 2Å 才送 wet lab。

Re-fold the designed sequence with AlphaFold 2/3 — does it match the target backbone (in silico self-consistency)? Only sequences with pLDDT > 80 and RMSD < 2Å go to the wet lab.

💡
套件位置：RFdiffusion 與 ProteinMPNN 都來自華盛頓大學 Baker Lab，2024 年諾貝爾化學獎主之一 David Baker 即此一系列工作的領導者。GitHub 都在 RosettaCommons 與 dauparas。 Where to find them: Both come from UW Baker Lab (David Baker, 2024 Nobel Chemistry). GitHub at RosettaCommons and dauparas.

二、四種典型設計任務

🔒

Binder design — 結合特定標靶

給定 target 蛋白上一塊 hotspot，設計能緊密結合它的小蛋白 (~50-150 aa)。已成功用於 SARS-CoV-2 spike 中和、IL-2 拮抗劑、PD-L1。

Given a target hotspot, design a small (~50-150 aa) protein that binds tightly. Used for SARS-CoV-2 spike neutralizers, IL-2 antagonists, PD-L1 binders.

🧪

Enzyme scaffolding — 活性中心移植

把已知催化三聯體 (e.g. Ser-His-Asp) 嵌進新 scaffold，實作從零到有的酵素 design。RFdiffusion-AA 可同時處理金屬輔因子。

Transplant a known catalytic triad (e.g., Ser-His-Asp) into a new scaffold to build enzymes from scratch. RFdiffusion-AA also handles metal cofactors.

🦠

Symmetric oligomers — 疫苗 nanoparticle

使用對稱性條件，設計 12-180 mer nanoparticle 顯示抗原。如 Neoflu7 流感疫苗已進入 phase I clinical trial。

Use symmetry conditioning to design 12–180-mer nanoparticles displaying antigens. E.g., Neoflu7 flu vaccine reached Phase I.

🛡️

Antibody design — RFdiffusion-Ab

2024 年發表的 antibody-specific RFdiffusion 變體，實作端到端 CDR 設計，已在多個實驗室拿到原子精度的 binding。

2024 antibody-specific variant; end-to-end CDR design, replicated by multiple labs at atomic accuracy.

git clone https://github.com/RosettaCommons/RFdiffusion && cd RFdiffusion
# Download SE3-Transformer weights (one-time, ~3GB)

python scripts/run_inference.py \

    inference.num_designs=100 \
    contigmap.contigs=[100] \
    inference.write_trajectory=False

# --- Step 2: Constrain a binder to a target hotspot ---
python scripts/run_inference.py \
    inference.input_pdb=target.pdb \
    contigmap.contigs=["A1-150/0 60-100"] \
    ppi.hotspot_res=["A33","A38","A41"] \
    inference.num_designs=200 \
    inference.output_prefix=outputs/binder
# Design sequences for the generated backbones
from protein_mpnn_utils import ProteinMPNN, parse_PDB

mpnn = ProteinMPNN(model_name="v_48_020").cuda().eval()
pdb_struct = parse_PDB("outputs/design_0.pdb")

seqs = mpnn.sample(
    pdb_struct,
    num_seq_per_target=8,
    sampling_temp=0.1,           # 0.1 = greedy & best success rate
    omit_AAs="CX",                 # skip Cys & non-canonical
)
for i, s in enumerate(seqs):
    print(f">design_{i}\n{s}")

四、設計流程怎麼挑？

🌳 Quick guide

目標：迷你 binder → RFdiffusion + ProteinMPNN + AF2-Multimer + ESMFold
目標：對稱奈米粒子 → RFdiffusion (symmetry mode) + ProteinMPNN
目標：抗體 → RFdiffusion-Ab → IgFold/AF-Multimer 驗證
目標：Enzyme → RFdiffusion-AllAtom (含金屬輔因子) + LigandMPNN
算力極少 → ESM-Design / Chroma 等 generative LM 替代品
陷阱

五、設計者最常掉的坑

⚠️
1. AF2 self-consistency 不等於實驗成功。實驗成功率仍只有 5-50%，依任務難度。需大量平行設計 (1000+) + 篩選。
2. 忽略表達性。AI 會設計出溶解度差、易聚集的序列；建議加入 NetSolP 或實驗室經驗 filter。
3. RFdiffusion 不知道生物實際限制。例如膜蛋白疏水性、二硫鍵正確配對需另外建模。 1. AF2 self-consistency ≠ experimental success. Wet-lab success is 5–50% depending on the task — generate 1000+ designs and filter aggressively.
2. Ignoring expressibility. AI happily designs poorly soluble, aggregation-prone sequences. Add a NetSolP filter or lab heuristics.
3. RFdiffusion is biology-naive. Membrane hydrophobicity, disulfide pairing — model these separately.

📝 概念小測 (3 題)

Q1. RFdiffusion 與 ProteinMPNN 在設計流程中的角色為？

(A) 兩者都是序列設計工具
(B) RFdiffusion 生成 3D 骨架；ProteinMPNN 為骨架選擇胺基酸序列
(C) 兩者都是 AlphaFold 替代品
(D) RFdiffusion 訓練 ProteinMPNN
✅ 正解 (B)

Q2. AlphaFold 的「self-consistency」檢查指什麼？

(A) AlphaFold 重複預測同一序列
(B) 把 ProteinMPNN 設計的序列丟回 AF 重新折疊，看是否回到目標 backbone
(C) AlphaFold 計算 confidence
(D) 兩個 AF 模型結果相似
✅ 正解 (B)

Q3. 即使 AlphaFold 顯示完美 self-consistency，實驗仍可能失敗，最常見原因？

(A) AlphaFold 都是錯的
(B) 設計序列可能溶解度差、表達低、或在多種其他構象都穩定
(C) 設計太多
(D) RFdiffusion 不支援
✅ 正解 (B)
